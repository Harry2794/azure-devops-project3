zure DevOps Project 3

Production-style CI/CD pipeline using GitHub Actions and an Azure Linux VM.

## Technologies

- Git
- GitHub
- GitHub Actions
- Linux
- Nginx
- Azure Virtual Machine
- Bash

## Objective

Build a controlled CI/CD pipeline that validates, tests, packages and deploys a website to an Azure Linux VM.

## Deployment Architecture

Developer → GitHub → GitHub Actions → Azure VM → Nginx
